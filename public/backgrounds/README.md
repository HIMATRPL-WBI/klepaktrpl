# Folder Foto Latar Belakang (Idle Screen)

Letakkan foto-foto Anda di dalam folder ini (`public/backgrounds/`).

Rekomendasi format:
- Resolusi: 1920x1080 (16:9)
- Format: .webp, .jpg, atau .png
- Nama file contoh: `foto1.webp`, `lab-trpl.jpg`, `kampus.png`

Setelah menaruh foto di sini, daftarkan nama filenya di `lib/idleNature.ts` pada array `LOCAL_BACKGROUNDS`.
